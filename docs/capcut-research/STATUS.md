### 4. 内容缺口（来自完整性检查）

1. **音频链路**：多轨混音、重采样与限幅、音画同步与时钟漂移、交叉淡化、响度归一（LUFS）、背景音乐闪避（ducking），都没有成章。
2. **剪辑态的人脸特效管线**：时间线上的已录制片段怎么做美颜、美型，例如：
   - 检测结果是否按素材时间离线缓存；
   - 分割、变速、倒放之后怎么复用这些结果；
   - 多人脸时怎么选人；
   - 预览降档时如何与导出结果保持一致。
3. **美体**：瘦身、长腿、小头的算法（基于骨骼或人体分割的形变、背景保护）。
4. **美颜子项**：亮眼、白牙、去黑眼圈、去法令纹、清晰、红润、匀肤、染发、漫画脸 / GAN 类特效，都只有参数名，没有机制。
5. **AR 贴纸**：贴纸如何锚定到关键点、表情/动作触发、3D 头部遮挡、多人脸时道具复制。
6. **通用画面特效的执行模型**：特效如何随片段时长推进时间（循环、拉伸）、多 pass 渲染图如何执行、render target 如何复用、渲染顺序。
7. **CapCut 自身的资源管理**：
   - 特效包与 SDK 版本的兼容协商；
   - 草稿打开时缺失资源如何补齐、失败如何降级；
   - 本地素材导入、代理文件、云草稿同步。
8. **iOS 端**：一手资料几乎为零。Metal 还是 GLES、CVPixelBuffer 零拷贝、后台导出都没有成章。
9. **色彩管理与 HDR**：BT.709 / BT.2020、HLG / PQ、色调映射、导出时的色彩元数据。
10. **相机拍摄链路**：采集 → 特效 SDK → 编码。
11. **预览渲染缓存与预合成**：哪些层预渲染、缓存何时失效、放内存还是磁盘。
